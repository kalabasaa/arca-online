# About

Arca is a web-based inventory management system built specifically for sari-sari store owners who need a simple way to track their products and organize their inventory.

The idea behind this project came from observing the challenges faced by small store owners when managing products manually. Many rely on notebooks or memory to track available stocks, which can lead to inaccurate records, missing information, and difficulty monitoring inventory.

Arca aims to provide a simple digital solution where store owners can manage products, update inventory records, and keep their store information organized.

This project also served as my learning experience in backend development, database management, and building structured web applications using PHP.

# Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/arca.git

cd arca
```

Move the project into your local server directory:

```
htdocs/arca
```

Create a MySQL database and import the provided SQL file.

Configure your database connection:

```php
Database Host: localhost
Database Name: arca
Username: root
Password:
```

Run the project:

```
http://localhost/arca
```
